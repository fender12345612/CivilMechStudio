## ✨ ไฮไลท์ฟีเจอร์เด่นในเวอร์ชัน 2.0

### 1. 📏 1D Beam Analysis (คาน 1 มิติ)
* วิเคราะห์คานด้วยระเบียบวิธีไฟไนต์เอลิเมนต์ (FEA) แบบเรียลไทม์
* **โหมด "ไม่คิดหน้าตัด" (Constant $EI$):** คำนวณหาแรงปฏิกิริยา $R$, แรงเฉือน $V$, โมเมนต์ดัด $M$, ความชันสัมพัทธ์ $EI\theta$, และการแอ่นตัวสัมพัทธ์ $EI\delta$ โดยไม่ต้องกำหนดหน้าตัด เหมาะสำหรับตรวจสอบคำตอบโจทย์ในตำราเรียน
* **โหมดคิดคุณสมบัติหน้าตัด (Engineering Mode):** คำนวณความเค้นดัด ($\sigma$), ระยะแอ่นตัวจริง ($\delta$), และความชันจริง ($\theta$)
* แผนภาพ SFD, BMD, Slope, Deflection, Bending Stress พร้อมแถบเลื่อน Probe HUD ตรวจสอบค่าทุกระยะ $x$
* รองรับระบบสัมผัส (Touch Scrubbing) เลื่อนนิ้วบนกราฟเพื่ออ่านค่าบนมือถือได้ทันที

### 2. 📐 2D Frame & Truss CAD (โครงข้อแข็งและโครงถัก 2 มิติ)
* วิเคราะห์โครงสร้าง 2 มิติด้วยวิธี **Direct Stiffness Method**
* ปรับแต่งโมเดลบนแคนวาสแบบ CAD Interactive: ลากย้ายจุดต่อ (Node Dragging) เพื่อคำนวณใหม่แบบเรียลไทม์
* **ระบบเรืองแสงโฟกัส (Glow Focus Effect):** เมื่อคลิกเลือกชิ้นส่วน (Member), จุดต่อ (Node) หรือแรงกระทำ (Point Load / UDL) ชิ้นส่วนนั้นจะเปล่งแสงนีออน (Neon Glow) แยกตัวออกมาอย่างเด่นชัด
* แสดงผลแผนภาพแรงดึง/แรงอัดตามแนวแกน ($N$), แรงเฉือน ($V$), โมเมนต์ดัด ($M$) และเส้นการเสียรูป ($Deflection$) ซ้อนบนโครงสร้าง
* รองรับคำสั่ง Undo / Redo และบันทึก Checkpoint ประวัติการแก้ไข

### 3. 🧊 3D Interactive Structural Viewer (แบบจำลองโครงสร้าง 3 มิติ)
* แสดงผลแบบจำลอง 3D มีความลึกเชิงพื้นที่ (3D Spatial Extrusion)
* **เมนูเปิด/ปิด โครงสีเทา (Ghost / 2nd Bay Toggle):** เลือกระหว่างแสดงเฉพาะโครงหลัก หรือแสดงโครงสร้างด้านหลัง (Bay Frame) และคานเชื่อม
* รองรับการหมุนรอบทิศทาง 360° (Orbit), เลื่อนมุมกล้อง (Pan) และซูมเข้า-ออก (Pinch-to-zoom บนมือถือ)
* แสดงแรงกระทำ, แรงปฏิกิริยา และแอนิเมชันการสั่น/การแอ่นตัวแบบเคลื่อนไหว (Dynamic Deflection Animation)

### 4. ⛺ 2D/3D Roof Truss Studio (โครงหลังคาเหล็กครบวงจร)
* ออกแบบโครงถักหลังคาเหล็กทรงจั่ว (Gable Roof Truss) แบบ Howe, Pratt, Warren และ Fink
* ออกแบบตามมาตรฐาน **วสท. / AISC (ทั้งวิธี ASD และ LRFD)**
* คำนวณแรงลมตามมาตรฐาน มยผ. / วสท. พร้อมระบบถอดปริมาณเหล็กและน้ำหนัก (BOQ)
* แผนภาพ 2 มิติ และมุมมอง 3 มิติตัวอาคารพร้อมแป Purlin และแผ่นหลังคา

### 5. 📱 รองรับการใช้งานบนโทรศัพท์มือถือเต็มรูปแบบ (Mobile & Touch Ready)
* Responsive Design จัดเลย์เอาต์อัตโนมัติ ไม่บีบอัดแคนวาส 2D บนหน้าจอขนาดเล็ก
* มีแถบนำทางด้านล่าง (**Mobile Bottom Navigation Bar**) สลับหน้าทำงานด้วยนิ้วโป้งมือเดียว
* ป้องกัน Safari / Chrome บนมือถือซูมเพี้ยนเวลาพิมพ์ตัวเลข
* ใช้นิ้ว 1 นิ้วลากหมุนโมเดล 3D และใช้ 2 นิ้วถ่าง/หุบเพื่อซูม (Pinch-to-zoom)

### 6. 🌓 โหมดมืด / สว่าง (Dark & Light Theme)
* สลับโหมดมืด-สว่างได้ง่ายด้วยปุ่มเดียว พร้อมไอคอน **🌙 ดวงจันทร์ (โหมดมืด)** และ **☀️ ดวงอาทิตย์ (โหมดสว่าง)**
* ปรับพื้นหลังตารางกริด (Blueprint Grid) ในโหมดมืดให้มืดสนิทสบายตา ถนอมสายตาขณะใช้งาน

### 7. 📄 รายงานการคำนวณ A4 PDF (Print & Export)
* หน้ารายงานแบบ Engineering Calculation Sheet ขนาดกระดาษ A4 มาตรฐาน
* จัดแบ่งหน้าอัตโนมัติ (3 แผ่น A4: ข้อมูลแบบจำลอง, ผลการวิเคราะห์ FEA, และแผนภาพสรุป)
* สามารถกดสั่งพิมพ์ (Ctrl + P) หรือบันทึกเป็น PDF ส่งงานวิศวกรรมได้ทันที

## 🚀 วิธีนำโปรเจกต์นี้ขึ้น GitHub Pages (เปิดใช้เว็บไซต์ฟรีใน 1 นาที)

1. เข้าเว็บไซต์ [GitHub.com](https://github.com) แล้วกด **New repository**
2. ตั้งชื่อคลัง เช่น `civilmech-studio` แล้วเลือกเป็น **Public** (ไม่ต้องติ๊ก Initialize with README เพราะในโฟลเดอร์นี้มีครบแล้ว)
3. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้นไป:
   - `index.html` *(ไฟล์หน้าเว็บหลัก)*
   - `solver1d.js`
   - `workspace2d.js`
   - `viewer3d.js`
   - `section-report-ai.js`
   - `truss-calculator.js`
   - โฟลเดอร์ `js/`
   - `.nojekyll` *(สำคัญมาก สำหรับให้ GitHub Pages โหลดไฟล์สคริปต์ได้ครบ)*
   - `README.md`
   - `LICENSE`
4. เมื่ออัปโหลดเสร็จ ให้ไปที่เมนู **Settings** ของ Repository บน GitHub:
   - เลื่อนแถบซ้ายไปที่ **Pages**
   - ในหัวข้อ **Branch** ให้เลือก `main` (หรือ `master`) และโฟลเดอร์ `/ (root)`
   - กดปุ่ม **Save**
5. รอประมาณ 30 วินาที GitHub จะสร้างลิงก์เว็บไซต์ให้ เช่น:
   `https://<ชื่อยูสเซอร์ของคุณ>.github.io/civilmech-studio/`  
   สามารถนำลิงก์นี้ไปเปิดใช้งานบนโทรศัพท์มือถือ แท็บเล็ต หรือคอมพิวเตอร์เครื่องไหนก็ได้ในโลกทันทีครับ!
